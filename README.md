# OpenGL Space Scene

An interactive 3D space simulation built using OpenGL and C++. The project features a dynamic space environment containing a planet, animated space character, rotating eye object, and a star-filled background rendered using Vertex Buffer Objects (VBOs). The application supports real-time interaction through keyboard and mouse controls, providing an engaging and immersive graphical experience.

---

## Features

* 3D space environment simulation
* Animated space character movement
* Rotating eye object with mouse interaction
* Dynamic star background using VBO rendering
* Planet scaling functionality
* Fullscreen mode support
* Real-time keyboard and mouse controls
* OpenGL primitive rendering (spheres, cubes, points)
* Interactive camera movement

---

## Technologies Used

* C++
* OpenGL
* GLUT
* GLEW
* Vertex Buffer Objects (VBO)

---

## User Controls

### Keyboard Controls

* `A` → Move character upward
* `D` → Move character downward
* `F` → Toggle fullscreen mode
* `ESC` → Exit program

### Mouse Controls

* Left Click → Rotate eye object
* Mouse Movement → Adjust camera view
* Mouse Wheel → Scale planet size

---

## System Components

### Space Environment

The simulation includes a moving star field background rendered efficiently using Vertex Buffer Objects (VBOs) for improved graphical performance.

### Animated Space Character

A fully rendered 3D space character composed of OpenGL primitives with animated movement and arm rotation.

### Interactive Eye Object

A rotating eye model that reacts to mouse input and continuously animates during interaction.

### Planet Rendering

A scalable 3D planet object that users can enlarge or reduce using mouse controls.
